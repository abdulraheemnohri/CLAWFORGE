# ClawForge AI V3 — High-Level Directory Layout

Welcome to the ultimate personal autonomous AI agent operating platform!

## Root Folders Overview
*   `apps/`: Host applications including the server, the web user interface, and the commander CLI client.
*   `packages/`: Core system modules and SDK layers (agent execution, providers connect, vector RAG database, policy checking, metrics logging, etc.).
*   `plugins/`: Active sandboxed third-party plugins.
*   `skills/`: Seeded and custom skill prompt/tool packages.
*   `workflows/`: Visual workflow canvas automation layouts.
*   `docs/`: Design documents and API guides.
